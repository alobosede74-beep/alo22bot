# @alo22bot - Telegram Text Analysis Bot

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/your-template)

A feature-rich Telegram bot for text analysis and plagiarism checking, hosted on Railway.

## ✨ Features

### 📝 Word Counter
- Count total words
- Count characters (with and without spaces)
- Count sentences and paragraphs
- Identify unique words
- Show top 5 most frequent words
- Estimate reading time

### 🔍 Plagiarism Checker
- Check text originality
- Score text similarity
- Provide detailed analysis
- Show source of check
- Multiple API fallbacks

### 💬 Interactive Features
- Auto-response to text messages
- Inline keyboard buttons
- Quick action buttons
- Real-time processing
